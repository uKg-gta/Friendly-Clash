# Friendly Clash — Android app

This is the native Android/iOS application workspace, initialized with Expo and TypeScript.

## Start

From this directory:

```bash
npx expo start
```

## Notes

- This app is intentionally a minimal foundation, not the finished home screen.
- The existing browser Ludo prototype remains under `prototype/ludo/`.
- The Android application identifier in `app.json` is provisional and must be confirmed before store release.
- The EAS project has not yet been created or linked.
